# SkyCitadel - Frontend

Клиентская часть цифровой экосистемы SkyCitadel. Это статический HTML/JS-фронтенд, который работает без серверного рендеринга.

## Особенности
- Мессенджер с видеозвонками (WebRTC)
- Социальная сеть (лента, посты, комментарии)
- Поисковик-агрегатор (Wikipedia, GitHub, StackExchange, DuckDuckGo)
- Карты с навигацией (Leaflet + Nominatim)
- Музыкальный плеер, календарь, калькулятор
- Единая система идентификации SkyID

## Безопасность
- Сообщения и посты шифруются на клиенте AES-256-GCM перед отправкой
- Сервер не видит содержимого сообщений
- Звонки P2P через WebRTC, шифруются сквозным способом

## Как запустить
1. Склонируйте репозиторий
2. Откройте `index.html` в браузере или раздайте через любой веб-сервер
3. Для полноценной работы нужно поднять серверную часть (репозиторий будет позже)

## Демо
Живая версия: https://skycitadel.onrender.com

## Статус
Проект в активной разработке. Серверная часть будет открыта позже, после аудита безопасности.
