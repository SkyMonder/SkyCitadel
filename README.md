# 🛡️ SkyCitadel — Твоя цифровая крепость

**Открытая, зашифрованная и неубиваемая цифровая экосистема на одном статическом HTML.**
Замена ВК, Telegram и Google, которую не заблокировать и не прослушать.

## 🚀 Что это такое?
SkyCitadel — это единая веб-экосистема, включающая в себя:
- **💬 Мессенджер** с аудио/видеозвонками (WebRTC P2P)
- **👥 Социальную сеть** с лентой, лайками и комментариями
- **🔍 Поисковик** без цензуры (агрегатор открытых API)
- **🗺️ Карты** с маршрутами (OpenStreetMap)
- **🎵 Музыкальный плеер** (радио)
- **📅 Календарь** с событиями и **🧮 Инженерный калькулятор**
- **🆔 Единый аккаунт (SkyID)** для всего и сразу.

## 🔐 Почему это безопасно?
- **Сквозное шифрование (E2EE):** Все сообщения и посты шифруются на твоём устройстве алгоритмом `AES-256-GCM` *перед* отправкой. Сервер хранит только «цифровой мусор», который не сможет прочитать.
- **Приватность по дизайну:** Пароли хешируются (`PBKDF2`), ключи живут только у тебя.
- **Неубиваемость:** Весь фронтенд — это один статический HTML-файл. Его можно раздавать с флешки, телефона или через IPFS. Заблокировать это невозможно физически.

## ⚙️ Как запустить у себя?
1. Клонируй репозиторий.
2. Открой `index.html` в браузере.
3. Для полной функциональности (чат, звонки, поиск) потребуется поднять свои микросервисы (инструкция появится позже).
*Или просто заходи в публичную крепость: [skycitadel.onrender.com](https://skycitadel.onrender.com).*
